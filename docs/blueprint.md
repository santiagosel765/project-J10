# **App Name**: Massenger

## Core Features:

- Secure Authentication: User authentication via email/password and Microsoft credentials login.
- Campaign Dashboard: Display a table of scheduled campaigns with details like type (WhatsApp/SMS), recipients, schedule, template name, and edit options.
- Campaign Details: Detailed view for each campaign showing specifics such as message type (WhatsApp/SMS), list of recipients, sending schedule, and template content.

## Style Guidelines:

- Primary color: Medium sky blue (#75A9FF) to evoke a sense of calm and communication.
- Background color: Very light cyan (#E0F7FA), almost white, creating a clean and uncluttered background.
- Accent color: Muted teal (#4DB6AC) to highlight key interactive elements without overwhelming the interface.
- Body and headline font: 'PT Sans' (sans-serif) for readability and a modern feel.
- Use minimalist icons to represent different campaign types and actions.
- A clean, table-based layout for the campaign dashboard, ensuring ease of navigation and information processing.
- Subtle transitions and animations on user interactions to enhance user experience without being distracting.
